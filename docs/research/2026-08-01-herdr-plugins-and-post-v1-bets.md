**Date:** 2026-08-01  
**Status:** Evidence retained; product response captured in roadmap

## Summary

Community Herdr plugins cluster around: file/diff review beside agents, project/layout recipes, worktrees, away-from-desk attention (phone/menu bar), multi-host unity, jump/palette, in-pane Chromium+CDP, editor nav polish, and GH issue/PR entrypoints.

Jordan’s product response:

| Cluster | Call |
| --- | --- |
| File/diff beside agent | **Yes** as Follow files (live touch + diff), not full IDE |
| Projects / recipes | **Already V1 / in progress** |
| Worktrees | **Deferred** (not a personal need now) |
| Away-from-desk | **Mac menu bar + push**; digests/approve paths largely exist; **no phone PWA** (native iOS later) |
| Multi-machine | Already covered enough |
| Command palette | Already covered enough |
| Browser | **Yes** as human in-app URL preview, not core CDP |
| Editor nav plugins | Skip |
| GH start-from-issue | Skip for now |
