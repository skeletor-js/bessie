The herd stays in the menu bar.

Close Bessie's window and your Herdr work keeps running. The menu bar shows what needs you, what is working, and the current totals. Select a row to open its pane.

Built for the Mac

More ways to run the herd.

Bessie adds native tools for launching, organizing, and returning to Herdr work.

Projects are reusable launch recipesDefine folders, tabs, split layouts, pane labels, and starting commands. Launch the recipe on this Mac or a remote Herd as ordinary Herdr work.
Local and remote, one fleetConnect multiple local and SSH Herds. Their workspaces and agents share one sidebar without pretending one connection is another.
Pin it or snooze itKeep important panes at the top, quiet noisy work for a bounded time, and wake it early without changing the underlying Herdr pane.
Native notifications, exact destinationChoose which state changes matter. A notification opens the exact pane that triggered it and never includes terminal contents.

Start local. Connect the Herds you already run.

Bessie 1.0.2 is a signed and notarized app for Apple-silicon Macs running macOS 14 or newer. It includes a compatible Herdr runtime for local work and connects to existing local or SSH Herds. Quit Bessie and the Herdr work keeps running.
